# Reiner Sibaja Matarrita

Ingeniero agrícola. Automatización y análisis de datos con R, Python (en progreso) y herramientas SIG.

## Proyectos

- **[portafolio-automatizacion](https://github.com/rsibajam-max/portafolio-automatizacion)**: sistema de captura, procesamiento y respaldo de datos meteorológicos del IMN. ~50 estaciones, actualización diaria, series desde hace 8 años.
- **[evapotranspiracion-metric](https://github.com/rsibajam-max/evapotranspiracion-metric)**: balance de energía satelital (METRIC) para estimación de evapotranspiración de cultivos a partir de imágenes Landsat 8 en el distrito de riego arenal tempisque (SENARA).
- **[utilidades-r](https://github.com/rsibajam-max/utilidades-r)**: scripts utilitarios para tareas locales, como un editor de PDFs sin subir archivos a internet.
- **[r-gis-herramientas](https://github.com/rsibajam-max/utilidades-r)**: scripts utilitarios para tareas locales, como un editor de PDFs sin subir archivos a internet.

## Herramientas

R · Python (en progreso) · SIG (QGIS, ArcGIS) · Automatización en Windows
